# Neolithia

Place historical events in chronological order on a world timeline.

**Play:** [https://kaegbert.github.io/neolithia/](https://kaegbert.github.io/neolithia/)

Static HTML/CSS/JS — deploy on GitHub Pages from the repository root (`main` branch, `/` folder).

## Local preview

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).
